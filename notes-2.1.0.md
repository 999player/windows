first release on github.

- auto updates. the app checks for new versions on launch and every few hours, downloads them in the background and installs next time you open it. switch in settings → updates if you'd rather not.
- renamed to 999player.exe. if you had the old build, run this setup over it, your likes and playlists stay.
- downloads go to music\999 player now.
- window snaps to screen edges and has a minimum size so the lyrics stop overlapping the list.
- cover art no longer covers the lyrics in the now playing view.
- volume shows a percentage while you drag.

999player-setup.exe installs it. 999player-ptb.zip is the portable version, unzip and run.
