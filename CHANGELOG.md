# changelog

## 2.1.0

- auto updates. the app checks for new versions on launch and every few hours, downloads them in the background and installs next time you open it. there is a switch in settings → updates.
- the window snaps to screen edges, win + arrow works, and it has a minimum size so the lyrics stop overlapping the list.
- cover art no longer overlaps the lyrics in the now playing view.
- volume shows a percentage while you drag.
- setup opens the app when it finishes.
